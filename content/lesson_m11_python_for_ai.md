# M11 – Python for AI (Level: L1–L4)

## Mục tiêu học:
- Hiểu và áp dụng Python từ cơ bản đến nâng cao trong AI, bao gồm lập trình, xử lý dữ liệu, và huấn luyện mô hình.
- Nắm các thư viện cốt lõi (NumPy, Pandas, Matplotlib, TensorFlow, PyTorch) và xu hướng 2025 (multimodal AI, federated learning).
- Phân tích rủi ro đạo đức (thiên vị dữ liệu, quyền riêng tư) và tuân thủ GDPR, UNESCO AI Ethics.

## Nội dung chính:
### 1. Python cơ bản (L1)
- Biến, kiểu dữ liệu, vòng lặp, điều kiện.
- Hàm, tổ chức code, module.
- Cấu trúc dữ liệu: list, dict, tuple, set.

### 2. Thao tác dữ liệu (L2)
- **NumPy**: Mảng, chỉ số, toán học cơ bản.
- **Pandas**: DataFrame, đọc CSV, xử lý dữ liệu thiếu, đạo đức dữ liệu (GDPR).
- **Matplotlib & Seaborn**: Trực quan hóa dữ liệu (biểu đồ, xu hướng).

### 3. Python cho AI nâng cao (L3-L4)
- **Scikit-learn**: Phân loại, hồi quy cơ bản.
- **TensorFlow/PyTorch**: Xây dựng mô hình neural network.
- **Hugging Face**: Xử lý NLP, multimodal AI.
- **Federated Learning**: Lập trình với TensorFlow Federated.

### 4. Cài đặt & môi trường
- Google Colab, VSCode, Vertex AI.
- Cài đặt thư viện: `pip install numpy pandas matplotlib tensorflow pytorch`.
- Quản lý môi trường: virtualenv, conda.

### 5. Đạo đức trong Python for AI
- **Rủi ro**: Thiên vị trong dữ liệu (VD: phân tích điểm học sinh), data leakage.
- **Nguyên tắc**: UNESCO AI Ethics (minh bạch, công bằng), GDPR (bảo mật dữ liệu).
- **Case study**: Phân tích dữ liệu học sinh bằng Pandas dẫn đến thiên vị nhóm yếu thế (liên kết M9).

## Bài thực hành gợi ý:
1. **Tính điểm trung bình** (L1): Viết chương trình nhận input điểm và tính trung bình.
2. **Phân tích dữ liệu** (L2): Đọc CSV điểm học sinh, vẽ biểu đồ điểm trung bình theo lớp.
3. **Phân loại văn bản** (L3): Sử dụng scikit-learn để phân loại đánh giá học sinh (tích cực/tiêu cực).
4. **Xây dựng mô hình** (L4): Thiết kế pipeline AI với TensorFlow để dự đoán nguy cơ bỏ học, tích hợp XAI (M18) và federated learning (M16).
