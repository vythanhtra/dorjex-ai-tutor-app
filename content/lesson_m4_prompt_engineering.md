# M4 – Prompt Engineering

## Mục tiêu học:
- Hiểu khái niệm và kỹ thuật viết prompt hiệu quả.
- Nắm các kỹ thuật zero-shot, few-shot, role prompting, và prompt đa mô thức.
- Phân tích rủi ro đạo đức trong thiết kế prompt.

## Nội dung chính:
### 1. Khái niệm Prompt Engineering
- **Prompt là gì?**: Hướng dẫn văn bản để điều khiển đầu ra của mô hình AI.
- **Cấu trúc prompt**:
  - **Task**: Mục tiêu (VD: tạo nội dung, dịch thuật).
  - **Context**: Bối cảnh (VD: bài đăng Instagram).
  - **Instruction**: Yêu cầu cụ thể (VD: ngắn gọn, vui tươi).

### 2. Các kỹ thuật Prompt Engineering
- **Zero-shot**: Không cần ví dụ (VD: “Dịch câu này sang tiếng Việt”).
- **Few-shot**: Cung cấp vài ví dụ (VD: “Dịch các câu sau, ví dụ: Hello → Xin chào”).
- **Role prompting**: Yêu cầu AI đóng vai (VD: “Hãy là một giáo viên”).
- **Prompt đa mô thức**: Kết hợp văn bản, hình ảnh (VD: “Mô tả hình ảnh này” – liên kết với M13).

### 3. So sánh GPT, Claude, Gemini
- **GPT (OpenAI)**: Tốt cho sáng tạo nội dung, cần prompt chi tiết.
- **Claude (Anthropic)**: Tốt cho phản hồi an toàn, đạo đức.
- **Gemini (Google)**: Tốt cho xử lý đa mô thức.

### 4. Đạo đức trong Prompt Engineering
- **Rủi ro**: Sinh nội dung sai lệch, vi phạm quyền riêng tư.
- **Nguyên tắc UNESCO AI Ethics**: Minh bạch, công bằng.
- **Ví dụ**: Prompt tạo quảng cáo có thể gây hiểu nhầm.

## Bài tập gợi ý:
1. **Viết prompt** (L1): Viết prompt để tạo nội dung Instagram (ngắn gọn, vui tươi).
2. **So sánh** (L2): Viết 2 prompt (zero-shot và few-shot) cho cùng một nhiệm vụ, so sánh đầu ra.
3. **Phản xạ đạo đức** (L3): Phân tích rủi ro đạo đức khi dùng prompt tạo quảng cáo. Đề xuất cải thiện dựa trên ISO/IEC 42001.
4. **Tư duy chuyên gia** (L4): Thiết kế prompt đa mô thức để tạo mô tả hình ảnh từ văn bản. Làm thế nào để đảm bảo tính chính xác?
