# M6 – Capstone & AutoEval

## Mục tiêu học:
- Thiết kế dự án thực chiến với GPT (VD: chatbot).
- Tích hợp AutoEval và sandbox đạo đức để kiểm định phản hồi.
- Hiểu cách log và tối ưu hóa phản hồi AI.

## Nội dung chính:
### 1. Thiết kế dự án thực chiến
- **Chatbot mini**: Thiết kế chatbot cho y tế, giáo dục, hoặc kinh doanh.
- **Cấu trúc**: Prompt + API (VD: OpenAI API) + UI (VD: Gradio).
- **Ví dụ**: Chatbot tư vấn học tập dựa trên GPT Builder.

### 2. AutoEval
- **AutoEval là gì?**: Đánh giá tự động chất lượng phản hồi AI (độ chính xác, tính phù hợp, đạo đức).
- **Tiêu chí đánh giá**: Logic, UX, đạo đức (liên kết với M10).

### 3. Sandbox đạo đức
- **Mô phỏng tình huống**: Kiểm tra phản hồi AI trong các trường hợp nhạy cảm (VD: tư vấn y tế).
- **Ví dụ**: Chatbot y tế trả lời sai lệch về liều thuốc.

### 4. Log và tối ưu hóa
- **Log phản hồi**: Ghi lại lịch sử tương tác để phân tích (VD: Python script đơn giản).
- **Tối ưu hóa**: Điều chỉnh prompt dựa trên log.

## Bài tập gợi ý:
1. **Thiết kế chatbot** (L1): Mô tả ý tưởng chatbot y tế hoặc giáo dục (100-150 từ).
2. **AutoEval** (L2): Viết 3 tiêu chí đánh giá cho chatbot của bạn (logic, UX, đạo đức).
3. **Phản xạ đạo đức** (L3): Phân tích rủi ro đạo đức của chatbot y tế. Đề xuất cải thiện dựa trên UNESCO AI Ethics.
4. **Tư duy chuyên gia** (L4): Thiết kế hệ thống AutoEval cho chatbot, tích hợp API và log phản hồi (mô tả cách thực hiện).
